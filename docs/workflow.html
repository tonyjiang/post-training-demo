Current experiment · our only GPU

NF4 + LoRA SFT · completed

Fixed hardware: one RTX 5070, 12,227 MiB VRAM. Frozen NF4 base, rank-8 adapters, batch 1 with accumulation 8. All experiments must fit this GPU.

4,241 training conversations across 13 source families, shuffled each epoch; 64 held-out conversations. Assistant-only loss, right truncation at 4,096 tokens, and Liger fused loss.

Completed 531 updates in 3h 13m. Held-out loss: 0.9288; peak allocated VRAM: 10.13 GiB. The adapter, latest two resumable checkpoints, logs and metrics are in outputs/sft/.

Deviation: QLoRA, a sampled mixture and truncation; Ai2 uses full-parameter OLMo-core SFT with 32K context and packing. Small evaluation completed: on 16 prompts per task, base and SFT both scored 13/16 on math; strict instruction following rose from 5/16 to 8/16. A 1,024-token generation cap affected many answers. See README for results and limitations.

First subset run complete

QLoRA DPO from our SFT adapter

Continue our SFT adapter with a frozen SFT reference sharing one NF4 base. Cache reference scores before updates. TRL supplies length-normalized DPO and a chunked LM head.

Default: 1,024 train / 64 held-out pairs sampled from one pinned Dolci shard; 2,048-token truncation, beta 5, peak LR 1e-5, 10% warmup and linear decay. Batch 1 pair, accumulation 8.

Completed on gaming-server on 2026-10-31: one epoch, 128 optimizer updates in 1h 37m; exit status 0. Held-out DPO loss 0.4118, peak allocated VRAM 10.19 GiB. Final adapter: outputs/dpo/final-adapter/. Small task evaluation complete: SFT → DPO gives GSM8K 13/16 → 10/16 and IFEval 8/16 → 9/16. All three new math failures hit the generation limit. The 2,048-output-token rerun completed at batch size 1: SFT → DPO gives GSM8K 13/16 → 12/16 and IFEval 7/16 → 7/16. DPO reused the completed SFT results; both exit statuses were 0.

Validation: two 2K updates passed at 9.93 GiB peak allocated VRAM; adapter reload verified.

Code: dpo/. Launch: scripts/start_dpo.sh. Ai2 recipe and deviations are pinned in configs/dpo.json.
